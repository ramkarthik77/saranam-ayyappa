# SARANAM v1 — Astro implementation preview

This is a non-production Phase 1 implementation branch based on the approved Q1–Q208 specification.

- Two public-language shells, five pillar destinations, Home, Search and Listen.
- Real semantic HTML, accessible navigation, responsive cinematic design, motion preference.
- Static section-discovery search only; **not** complete prayer search.
- PWA preview shell only; **not** verified offline-essential content.
- No copyrighted lyrics, unreviewed religious instructions, unlicensed recordings, or personal data.
- All pages are `noindex,nofollow` until Gate C.
- Original production website and draft Telugu prayer PR #2 remain untouched.

```bash
npm install
npm run build
npm run test:output
npm run dev
```

The build requires Astro 5 and Node 22. The production merge must be blocked until the required text, rights, offline, editorial, and three-audio-track acceptance gates are verified and the owner explicitly approves the specific release. This preview is NOT Gate C.
